# AION 2 — индекс на документите

## Постоянни знания

Папката `knowledge/` съдържа актуалното състояние по конкретни теми. Един факт се обновява на постоянен път и запазва същото `id`.

## Новини

Папката `news/YYYY/MM/` съдържа отделни събития. Историческите файлове, мигрирани от старите дневни папки, са маркирани с `archived: true` и `notify_discord: false`.

## Критични правила

- Официална KR/TW публикация не е автоматично потвърждение за Global.
- `source_type`, `region` и `verification` са отделни полета.
- Само нов документ с `document_type: news` и `notify_discord: true` се публикува в Discord.
- Не се създават празни документи и не се дублира вече известна информация.
