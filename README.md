# AION 2 — Global News Tracker

Това repository проследява **AION 2 Global** и отделно маркирани KR/TW промени, които могат да са релевантни за бъдещата Global версия.

## Структура

```text
docs/aion-2/
  knowledge/<topic>/<file>.md
  news/<year>/<month>/<date>-<event>.md
schema/document.schema.json
```

- `knowledge/` съдържа текущи постоянни факти по конкретна тема.
- `news/` съдържа отделни събития и исторически сигнали.
- Всеки документ има YAML frontmatter с устойчиво `id`, регион, надеждност, източници и timestamp.
- Старите дневни папки са мигрирани; историята им остава достъпна чрез Git.

## Discord

Discord workflow-ът обработва само файлове под `docs/aion-2/news/**`, при които:

```yaml
document_type: news
notify_discord: true
```

Постоянните knowledge документи и мигрираните исторически новини не предизвикват известия.

## Надеждност

- `confirmed` — потвърдено от подходящ първичен източник;
- `unconfirmed` — непотвърдено или технически сигнал без достатъчен diff;
- `likely_false` — има сериозни основания твърдението да е невярно;
- `mixed` — исторически сборен документ с различни статуси.

Ключово правило: официална KR/TW информация не се представя като Global потвърждение без отделно доказателство.
